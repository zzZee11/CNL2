# Lightweight Human-Detection & Tracking Dependencies for Raspberry Pi 4 (64-bit OS)
# ----------------------------------------------------------------------------------
# This system is specifically architected for the Raspberry Pi 4's ARM Cortex-A72 CPU,
# requiring minimal RAM (<60 MB) and eliminating heavy PyTorch/CUDA overhead.
#
# Recommended Setup on 64-bit Raspberry Pi OS (Python 3.11+ / Debian Bookworm):
#   1. sudo apt update
#   2. sudo apt install -y python3-opencv python3-numpy python3-pip
#   3. pip install ai-edge-litert
#
# Or within a dedicated virtual environment:
#   python3 -m venv vision_env --system-site-packages
#   source vision_env/bin/activate
#   pip install ai-edge-litert
# ----------------------------------------------------------------------------------
